Wat doe ik

Design + build
Van eerste idee tot een werkende website. Ik combineer UX, UI en visual design met Framer development om projecten van A tot Z te realiseren.
Strategie → UX → UI → Design → Framer → Lancering.



Klein team, grote mogelijkheden.
Ik werk zelfstandig, maar zelden alleen. Voor specifieke onderdelen werk ik samen met een netwerk van grafisch ontwerpers, developers en andere specialisten. Zo ontstaat voor ieder project het team dat nodig is.

Wie help ik

Ik werk graag samen
met merken, organisaties, bureaus en ondernemers die een sterke digitale ervaring willen neerzetten. Van een nieuwe website tot een digitaal product, van een eerste idee tot een compleet uitgewerkt eindresultaat.
